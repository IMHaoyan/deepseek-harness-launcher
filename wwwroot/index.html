手动安装指引（官方方式）

        

          
Node.js：到 nodejs.org 下载 LTS 安装包（需 22.19+ 或 24+）。

          
DeepSeek Harness：安装 Node.js 后执行 npm i -g @deepseek-ai/dsh（国内网络可在末尾加 --registry https://registry.npmmirror.com），再执行 dsh web；或克隆仓库 git clone https://github.com/deepseek-ai/deepseek-harness.git 后 pnpm install && pnpm run build。

          
安装完成后回到本页点击"重新检测"。
