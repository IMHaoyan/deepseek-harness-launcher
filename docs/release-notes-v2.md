# DSHL 发布说明（重写版 · 待确认）

重写原则（对齐 Claude Code changelog 的写法）：
- 每条一行，动词开头（新增 / 优化 / 修复 / 调整 / 移除），只讲用户能感知的变化；
- 不写根因分析、文件路径、代码函数名、验证过程；
- 一个版本内按「新增 → 优化 → 调整 → 修复」分组，空组不写；
- 版本头只留版本号 + 日期。

---

## v1.1.9 — 2026-09-08

**新增**
- 设置页新增「插件市场」：一键安装 DSH 内置的可视化插件市场（dshmarket），装完自动重启服务生效；已安装时按钮变为「卸载」。
- 插件市场默认安装：升级后首次启动自动装上（每个版本只尝试一次），用户主动卸载后不再自动装回。

**调整**
- 余额接口设置入口从设置页移到主页余额卡片：刷新按钮右侧新增 ⚙ 图标。

**修复**
- 修复点击「停止服务」无反应、服务仍在运行的问题；停止过程中按钮显示「停止中…」并禁用，不再重复弹出「服务已停止」。

## v1.1.8 — 2026-09-08

**新增**
- 「上次未正常退出」提示卡新增「知道了」按钮：关闭后同一次崩溃不再重复提示，只有新的崩溃才重新提醒。

**修复**
- 修复开发模式每次热重启（`npm run dev` / F5）都被误判为崩溃并生成诊断报告的问题。

## v1.1.7 — 2026-09-08

**新增**
- 崩溃自愈：服务反复启动失败时自动回退到上一个正常配置；仍失败则停止自动恢复并提示，不再无限重启。
- 健康快照：服务稳定运行后自动保存配置快照，供回退使用。
- 异常退出检测：上次未正常退出时提示并自动生成诊断报告（已脱敏，保留最近 3 份）。
- 日志脱敏：日志与反馈内容中的 API Key、Token、鉴权头、URL 凭据自动打码。

**修复**
- 修复 DSH 更新后新版启动失败仍提示「已更新」的问题，现在会明确报错并回滚。
- 修复反馈内容可能外泄 DSH 启动令牌的问题。
- 修复读取用户 PATH 失败时覆盖整条 PATH 的问题。
- 修复面板启动期间显示「已停止」、可重复点击「启动服务」的问题；新增「正在启动服务…」状态。

**移除**
- 移除「启用标签和内部分屏功能」设置项，独立窗口固定为精简标题栏。

## v1.1.6 — 2026-09-04

## v1.0.4 — 2026-08-15

首个公开发布版。
