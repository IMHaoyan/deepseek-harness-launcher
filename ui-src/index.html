手动安装指引（官方方式）

        

          
Node.js：到 nodejs.org 下载 LTS 安装包（需 22.19+ 或 24+）。

          
DeepSeek Harness：安装 Node.js 后执行 npx @deepseek-ai/dsh web；或克隆仓库 git clone https://github.com/deepseek-ai/deepseek-harness.git 后 pnpm install && pnpm run build。

          
安装完成后回到本页点击"重新检测"。

说明

        

          
默认无需配置：自动读取 DSH 配置（`~/.dsh/.credentials.yaml` 的 `DEEPSEEK_API_KEY` 与 `~/.dsh/settings.yaml` 的 `llm-deepseek.baseURL`），打开面板即自动查询余额（每 3 分钟自动刷新）。

          
自定义：在此页填写 API Key / 查询接口后点"测试并保存"——连通（正确获取到余额）即自动保存并立即生效；查询接口需实现 DeepSeek 余额 API（`GET {接口}/user/balance`）。

          
清除：清空已保存的自定义设置，回到自动读取 DSH 配置。
